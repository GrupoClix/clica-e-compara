# Roadmap

1. **Etapa 1 (atual): protótipo público.** Comparador, histórico local, PWA. Coleta de feedback de amigos.
2. **Etapa 2: leitor de código de barras.** Câmera + consulta de produto (Cosmos / Open Food Facts) via backend Python (FastAPI), para preencher o nome do produto.
3. **Etapa 3: registro anônimo.** Banco (Supabase, sem login) com estabelecimento, produto, embalagens e preços. Ver `modelo-de-dados.md`.
4. **Etapa 4: painel B2B** para estabelecimentos verem os produtos mais pesquisados.

Princípio: nunca coletar dado pessoal nem identificador de aparelho.
